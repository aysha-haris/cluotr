CLOUTR is built for **Pinterest traffic** and **affiliate growth**.

## What this foundation includes

- File-based MDX content for writers
- PostgreSQL schema for products and collections
- Reusable SEO utilities with JSON-LD
- Security headers and environment validation

Add new posts by dropping `.mdx` files into `src/content/blog/` — no code changes required.
